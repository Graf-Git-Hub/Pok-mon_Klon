# Game Boy art v5 Implementation Plan

Goal: Improve the existing isolated GB prototype with original readable pixel art and real movement animation.
Architecture: Preserve the Python atlas generator and self-contained Canvas preview. Keep all 39 terrain IDs; put transparent actor frames and foreground masks in a separate small sheet. No main-game renderer, APK or save changes.
Tech stack: Python/Pillow, JavaScript Canvas, Playwright Chromium.
Spec: echo-chroniken/docs/gb-classic/ASTRA_WORK_GRAFIK_AUFTRAG.md

Constraints: exact existing four shades; 16px cells; 10x9 phone and 16x9 TV camera; four existing doors and route exits; only town/forge layout edits.
Review focus: animation at blocked movement; pause/blur during held input; transparent white clothing; foreground overlaps at camera edges; door return and rapid successive inputs.

1. Study Red/Blue/Yellow reference sheets, map composition and animation code; document observations without shipping any source art.
2. Add failing browser animation checks. Author a 4-direction x 3-frame original protagonist and two NPC silhouettes; preserve terrain slots.
3. Refine shared tiles with original pixel construction. Tree canopy extends eight pixels above its collision cell; furniture extends four. Transparent masks and Y-sorted actors produce proper occlusion. Tall grass uses a separate blade mask.
4. Add movement interpolation, alternating walk phases and idle reset to common step path. Keyboard, touch and gamepad use that path. Retain instant logical position updates for current tests, render interpolation separately.
5. Preserve village coordinates; improve door paths. Simplify forge furniture layout without changing its doorway. Build deterministic artifacts.
6. Run existing node/browser tests plus animation/palette/occlusion and input checks. Capture real screenshots and an animated canvas recording, inspect images.
7. Commit an isolated branch, open draft PR against supplied base. Publish a new isolated preview URL, verify hosted build, document hardware limits and update project handoff/task/changelog.
